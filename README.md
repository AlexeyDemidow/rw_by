# 🚂 PASS.RW.BY Parser

Парсер расписания поездов с сайта [pass.rw.by](https://pass.rw.by) (Белорусская железная дорога).

## 📌 О проекте

Проект в ранней стадии разработки. Асинхронно запрашивает страницу поиска по маршруту, вытаскивает строки с поездами и парсит их в структурированный JSON — тип поезда, номер, станции отправления/прибытия, время в пути, дни курсирования, типы вагонов, наличие мест и цены.

## 🚧 Статус

Ранняя разработка. Основной функционал — парсинг одной страницы по заданному маршруту и дате — уже работает.

## 📂 Структура

- `main.py` — асинхронный клиент, загрузка страницы и сбор результатов
- `parse_text.py` — парсинг отдельной строки поезда в словарь

## 🛠 Стек

- Python 3.10+
- `httpx` — асинхронные HTTP-запросы
- `BeautifulSoup4` — разбор HTML
- `fake-useragent` — подмена User-Agent

## ⚙️ Использование

```python
from_station = 'Минск-Пассажирский'
to_station = 'Светлогорск-на-Березине'
date = '2026-10-23'
```

Запуск:

```bash
python main.py
```

Результат — JSON-массив объектов поездов.

## 🗺 Планы

- **Телеграм-бот** с системой оповещений о закреплённых маршрутах:
  - пользователь добавляет маршрут (откуда → куда) и дату/период
  - бот периодически проверяет расписание и наличие мест
  - при появлении билетов или изменении цен присылает уведомление
- Поддержка нескольких маршрутов за раз
