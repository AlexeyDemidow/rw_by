# 🚂 rw_by — API расписания поездов pass.rw.by

Асинхронный HTTP-сервис на FastAPI, который по маршруту и дате запрашивает страницу поиска на [pass.rw.by](https://pass.rw.by) (Белорусская железная дорога), разбирает список поездов и отдаёт его в виде типизированного JSON: поезд, станции, время в пути, дни курсирования, типы вагонов, количество мест и цены.

## 📌 Статус

Ранняя стадия разработки. Работает: REST-эндпоинт для поиска поездов по одному маршруту и дате, ретраи, валидация входных данных и ответов, обработка ошибок.

Не реализовано: кэш, ограничение числа запросов к сайту, тесты, Docker, Telegram-бот (см. [Планы](#-планы)).

## ✨ Возможности

- Асинхронные запросы через `httpx` с одним общим клиентом на всё приложение (создаётся в `lifespan`)
- Повторные попытки с экспоненциальной задержкой и jitter при сетевых ошибках, 5xx и 429
- Парсинг HTML (`BeautifulSoup4`) и разбор строк поездов регулярными выражениями
- Pydantic-модели ответа: контракт API виден в OpenAPI
- Валидация даты на уровне FastAPI (некорректная дата → `422`)
- Различие ошибок: сайт недоступен или вёрстка изменилась → `502`, неверный маршрут → `404`

## 🛠 Стек

- Python 3.10+
- FastAPI + Uvicorn
- httpx
- BeautifulSoup4
- Pydantic v2 + pydantic-settings
- fake-useragent

## 🔌 API

### `GET /trains`

| Параметр      | Тип                  | Описание                      |
|---------------|----------------------|-------------------------------|
| `dep_station` | string               | Станция отправления           |
| `arr_station` | string               | Станция прибытия              |
| `trip_date`   | date (`YYYY-MM-DD`)  | Дата поездки                  |

Пример запроса:

```bash
curl -X 'GET' \
  'http://127.0.0.1:8000/trains?dep_station=...&arr_station=...&trip_date=....-..-..' \
  -H 'accept: */*'
```

Пример ответа (значения условные):

```json
{
  "trains": [
    {
      "train_type": "...",
      "train_number": "...",
      "from_station": "...",
      "to_station": "...",
      "dep_time": "...",
      "dep_station": "...",
      "arr_time": "...",
      "arr_station": "...",
      "duration": ".. ч .. мин",
      "days": "..., ежедневно",
      "badges": [],
      "carriages": [
        {
          "type": "...",
          "options": [
            {
              "seats": 999,
              "price": "..."
            }
          ]
        },
        {
          "type": "...",
          "options": [
            {
              "seats": 99,
              "price": "..."
            }
          ]
        }
      ]
    },
    {"...": "..."}
  ],
  "order_url": "https://pass.rw.by/ru/route?from=...&to=...&date=....-..-.."
}
```

`price` сериализуется строкой (тип `Decimal` в Pydantic v2). `order_url` — ссылка на страницу поиска на pass.rw.by для оформления билета.

### Коды ответов

| Код   | Когда                                                                 |
|-------|-----------------------------------------------------------------------|
| `200` | Запрос выполнен (список `trains` может быть пустым — поездов нет)     |
| `404` | Сайт ответил 400/404, как правило неверная станция                    |
| `422` | Некорректные параметры запроса (например, формат даты)                |
| `502` | pass.rw.by недоступен, исчерпаны попытки или изменилась вёрстка       |

## ⚠️ Замечание

Проект не связан с Белорусской железной дорогой. Данные берутся с публичной страницы сайта, поэтому формат ответа зависит от его вёрстки. Не отправляйте слишком частые запросы, чтобы не создавать лишнюю нагрузку на сайт.
